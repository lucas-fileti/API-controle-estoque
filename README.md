# API Stock Control

API simples para controle de estoque, criada com FastAPI. O projeto organiza produtos, categorias, compras de malha e entradas de estoque, mantendo um resumo com quantidade total de peças e valor de custo armazenado.

O objetivo é servir como base para um sistema de gestão de estoque voltado para produção e venda de peças, com uma estrutura fácil de entender e evoluir.
